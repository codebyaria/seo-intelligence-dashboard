# SEO Intelligence Dashboard — Project Context

## Objective

Phase 4 of the DigiAgency application portfolio. A React-based SEO analytics
dashboard that demonstrates Astro + React + TypeScript + REST API boundary,
built on a clearly labeled simulated dataset (GSC / GA4 / Microsoft Clarity
shapes). It must NOT imply access to real client accounts.

## Source of Truth

- `../docs/master-prd.md` — Section 9 (Project PRD 03).
- `../docs/status.md` — current phase state.
- `../docs/roadmap.md` — Phase 4 task list.
- `../docs/honesty-and-claims.md` — "Demo Using Simulated Data" label rules.
- `../docs/architecture-decisions.md` — ADR-005 (Editorial Technical) applies.

## Working Rules

- Follow the same quality gate pattern as `portfolio-site/` and
  `local-business-growth/`: Vitest, ESLint (`--max-warnings=0`), Prettier,
  `tsc --noEmit`, `astro build`.
- Data is **simulated and deterministic**. Label every surface that shows
  numbers: "Demo project using simulated SEO data."
- No real GSC / GA4 / Clarity credentials. Simulated adapters only.
- Keep secrets out of the repository; document env via `.env.example`.
- Update `../docs/status.md` after a verified deliverable.

## Architecture (PRD 9.5 — initial slice)

```
src/data/         Static simulated dataset (TypeScript modules + JSON seeds)
        ↓
src/lib/          Pure data-processing functions (filter / aggregate / trend)
        ↓
src/pages/api/    Astro endpoints (REST boundary: /api/overview, /api/keywords,
                  /api/pages) — read query string, return JSON
        ↓
src/components/   React island: <Dashboard client:load /> fetches endpoints,
                  renders KPI cards, tables, filter controls, states.
```

## Project Boundaries

- This directory is an **independent Git repository**.
- Astro shell handles SEO metadata, robots, sitemap for the dashboard's own
  marketing surface (one `/` page explaining the demo).
- Dashboard UI lives behind the shell as a React island on `/dashboard/`.
- Does not modify `portfolio-site/` or any other sibling project.

## Honesty Labels
